# 💅 AN Studio
## ✨ Descripción del Proyecto
AN Studio es una página web de reservación de citas de maquillaje y uñas. La cual permite a las clientes explorar los servicios disponibles, 
para agendar su cita de forma rápida y sencilla desde cualquier dispositivo.

## 💎 Características Principales
•	Servicios: Visualización de servicios organizados por categorías (Maquillaje Básico, Uñas Naturales, 
Maquillaje para Bodas, Graduaciones, Uñas Acrílicas, Nail Art).
•	Reservación de Citas: Sistema funcional para agendar, modificar y cancelar citas con fecha, hora y monto total a pagar.
•	Autenticación de Usuarias: Registro e inicio de sesión seguro para clientes.
•	Panel Administrativo: Gestión total de servicios, disponibilidad, agenda y clientes.
•	Buscador de Disponibilidad: Filtro rápido por fecha, servicio, precio.

## 🚧 En Desarrollo
•	Recordatorios Automáticos: Notificaciones por WhatsApp o correo antes de la cita.
•	Galería de Trabajos: Portafolio visual para inspirar a las clientas.

## 🔧 Tecnologías Utilizadas
El proyecto está construido utilizando un stack potente y escalable:
1.	HTML5 & CSS: Estructura y diseño responsive.
2.	Python 3.13: Lenguaje de programación principal.
3.	Django 6.0.1: Framework web para la lógica de negocio y seguridad.
4.	MySQL 2.2.7: Base de datos robusta para el manejo de citas, servicios y usuarias.

## 🚀 Instalación
Sigue estos pasos para ejecutar el proyecto localmente:
### 1. Clona el Repositorio
Clona el repositorio desde GitHub:
bash
git clone https://github.com/anajesselle25/pagina_unas_an.git
cd pagina_unas_an

### 2. Instalación de Archivos
- Creación de entorno virtual
•	Bash
•	Python -m venv env
•	env\scripts\activate

- Instalación de librerías y dependencias
o	Bash
o	pip install -r requirements.txt

### 3. Ejecución
Verificar funcionalidad:
bash
python manage.py runserver
